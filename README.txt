HOW TO GET THE APK (free, no Android Studio needed)
1. Create a free account at github.com and make a NEW repository (e.g. kirana).
2. Click "uploading an existing file" and drag in ALL files and folders from this
   project (www, .github, package.json, capacitor.config.json). Commit.
   Tip: the ".github" folder must be uploaded too (it is hidden on some computers).
3. Open the repository's "Actions" tab. "Build Android APK" runs automatically (~5 min).
4. Open the finished run, download "GharKaKirana-apk" (a zip) and extract app-debug.apk.
5. Copy app-debug.apk to your Android phone and install it
   (allow "Install unknown apps" when asked).
